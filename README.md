# 恩典手帳｜My Faith Journal — 第一階段

這是第一階段的手機版介面骨架，使用純 HTML、CSS、JavaScript，無需安裝套件或執行建置指令。

## 檔案
- `index.html`：五個主要頁面的介面
- `style.css`：米白、米色、鼠尾草綠的手帳風格
- `app.js`：底部導覽與基本互動
- `manifest.json`、`service-worker.js`、`icons/`：PWA 安裝及離線介面快取

## 第一階段範圍
已完成五個頁面的切換與介面預覽。讀經進度、筆記、書籍及資源目前仍是介面示意，尚未加入資料儲存功能。沒有建立假紀錄，也沒有連接雲端服務。

## 安全
不要把個人筆記、照片或 ZIP 備份上傳到這個公開 Repository。未來的個人資料功能會留在使用者 iPhone 的本機儲存空間。
